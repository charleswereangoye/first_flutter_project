# First Flutter Project

This is my first Flutter mobile application for my school assignment.

## About
The app is a very simple "Hello World" program. When you open it, it displays "Hello World" and my name, Charles Were Angoye, on the main screen.

## How to run
To run this app on your computer:
1. Make sure you have Flutter installed.
2. Connect your phone or start an Android emulator.
3. Run `flutter run` in your terminal.
